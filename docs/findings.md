## B. 원본 조건 (r_pin=75um, h_pin=300um) 기준값

```
R_th      = 23.7975 K/W
Q_conv    = 2.7314 W
T_max     = 358.150 K   (= 고정온도 경계값, 아래 D-1 참조)
T_max_hs  = 344.522 K
T_min     = 340.976 K   (핀 끝단)
A_conv    = 3.6839 mm^2
```

기하 검산: 손계산 대류면적 = 핀측면 2.262 + 핀상면 0.283 + 베이스노출 1.157
= 3.702 mm^2. FEM 이산화값 3.684 mm^2 와 일치(-0.5%, 원통 패싯팅).

`z_hs` 검산: `t_die + 12*(t_ncf + t_die) = 32 + 12*47 = 596 um`. 원본 파라미터
`z_hs = 596e-6` 과 정확히 일치 -> **로직 다이 1장 + DRAM 12단 구조로 확정.**

## C. 모델링 치환 (원본과의 차이)

| 항목 | 원본 COMSOL | 본 구현 |
|---|---|---|
| TSV / 범프 | 개별 형상 5,696개 | 층 단위 이방성 유효물성 |
| 스택 층 | NCF/다이 25개 볼륨 | 등가 이방성 블록 1개 (`merged`) |
| 열전도 | 등방 스칼라 | 이방성 대각텐서 |

유효물성 계산 결과:

```
다이층 (Si + TSV Cu, f=0.0641):  k_xy = 138.78,  k_z = 147.31  W/(m K)
NCF층 (NCF + 범프 Cu, f=0.1002): k_xy =   1.22,  k_z =  40.97  W/(m K)
```

NCF 층의 이방성이 33배다. 범프가 수직 열전도를 지배하며, NCF 자체의 k=1.0은
면내 방향에서만 병목으로 작용한다. 이 치환이 없으면 스윕 1케이스가 수천 개
형상 재빌드를 요구해 루프를 돌릴 수 없다.

층 병합은 층상매질의 엄밀해(직교=직렬 조화평균, 평행=병렬 산술평균)를 쓰므로
치환 오차는 유효물성 근사(Maxwell-Eucken)에서만 발생한다.
`resolve_layers="full"` 로 층을 전부 펼쳐 이 차이를 측정할 수 있다.

## D. 발주처에 확인이 필요한 소견 2건

여기가 이번 분석의 핵심이다. 둘 다 **자동화 이전에** 정리되어야 한다.

### D-1. 온도 기반 목적함수는 작동하지 않는다

원본 모델에는 열원(Heat Source) 노드가 없다. 대신 `temp1`이 특정 면을
358.15 K(85 degC)로 **고정**한다. 그 결과:

- 전 스윕 케이스에서 `T_max = 358.150 K`로 **완전히 고정**됐다.
- `T_max_stack` 도 마찬가지로 358.150에서 움직이지 않는다.
- 즉 원본의 파생값 `max1`/`max2`(MaxVolume, 표현식 `T`)를 최적화 지표로 쓰면
  **모든 설계가 동점**이 된다.

설계에 반응하는 것은 `R_th`와 `Q_conv` 뿐이다. (원본 `max1`은 `box13` 박스
선택 영역 한정이므로, 그 박스가 고정온도면을 제외했다면 변동이 생길 수 있다.
이 확인은 COMSOL 실행이 필요하다.)

**정션온도(T_j) 스펙으로 판정하려면 모델을 열원 방식으로 바꿔야 한다** —
로직/DRAM 다이에 실제 발열을 W 단위로 주고 고정온도 경계를 제거하는 구조 변경이다.
그 경우 HBM 실제 전력값이 필요하다.

### D-2. 최적화가 탐색 상자 모서리로 발산한다 (더 중요)

r_pin x h_pin 2D 그리드(25케이스) 결과, 최적점이 항상 **탐색 범위의 모서리**에 붙는다.
내부 최적해가 존재하지 않는다.

```
r_pin[um]  h_pin[um]   R_th[K/W]   Q[W]
       55        150     34.5   ...
       75        300     23.80    2.73    <- 원본 조건
      135        900     10.92    5.95    <- "최적" (= 탐색 상한)
```

원인은 명확하다. **`h = 15000 W/(m^2 K)`가 형상과 무관한 상수로 박혀 있다.**
실제로는 핀을 키우거나 촘촘히 하면 유로가 좁아져 압력강하가 늘고 h가 **떨어진다**.
그 커플링이 모델에 없으므로 표면적을 늘리면 무조건 이득이 되고, 최적화는
"핀을 무한히 크게"라는 무의미한 답으로 수렴한다.

이 상태로 자동화 루프를 돌리면 루프는 정상 동작하지만 **결과가 공학적으로 무의미하다.**
해결하려면 셋 중 하나가 필요하다:

1. **h를 형상의 함수로** — 핀 배열 상관식(예: Zukauskas 관군 대류)으로 h(r_pin, p, n, 유속)을 준다. 가장 싸다.
2. **켤레열전달(CHT)** — 유동을 실제로 풀어 압력강하와 h를 동시에 얻는다. 원본에는 CFD 모듈이 없다.
3. **제약 최적화** — 압력강하 또는 펌핑파워 상한을 제약으로 걸고 R_th를 최소화한다.

**그리고 h=15000의 근거 자체를 확인해야 한다.** 공기 자연대류 5~25, 강제대류 25~250 대비
15000은 액침냉각 / 제트 임핀지먼트 / 마이크로채널 수랭 영역의 값이다.

## E. 결론

- 루프 인프라(지오메트리 생성 -> 메시 -> 솔브 -> 판정 -> 로깅)는 **검증 완료, 동작한다.**
  케이스당 0.2~1.3초로 수백 케이스 스윕이 부담 없다.
- 목적함수는 플러그인으로 분리해 두었으므로 판정 기준이 확정되면 파일 하나만 바꾸면 된다.
- **다만 D-2가 해결되기 전에는 최적화 결과를 설계 결정에 쓰면 안 된다.**
  현재 모델은 "표면적이 클수록 좋다"는 답만 낼 수 있다.
